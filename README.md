# Real-Time Interactive Dashboard in C++ (ESP8266 & DHT11)

Проєкт сучасного вебдашборду для мікроконтролера **ESP8266 (Wemos D1 mini)** та датчика температури й вологості **DHT11**. Дані передаються у форматі **JSON** та оновлюються на вебсторінці в реальному часі за допомогою **JavaScript (AJAX / Fetch API)** без потреби перезавантажувати сторінку.

---

## 🛠 Технології та Бібліотеки

* **Платформа:** ESP8266 (Arduino / PlatformIO)
* **Мережевий стек:** `ESP8266WiFi` (режим STA з тайм-аутом з'єднання)
* **Вебсервер:** `ESP8266WebServer` (обробка HTTP GET запитів, видача HTML та JSON)
* **Датчик:** `DHT sensor library` для роботи з DHT11
* **Фронтенд:** HTML5, CSS3 (сучасні картки та стилі), JavaScript (`fetch` + `setInterval`)

---

## 📌 Підключення (Wiring)

| Пін ESP8266 (Wemos D1) | Пін датчика DHT11 | Опис |
| :--- | :--- | :--- |
| **3V3 або 5V** | VCC | Живлення датчика |
| **GND** | GND | Заземлення |
| **D2** | DATA (OUT) | Передача даних (цифровий пін) |

---
